过期传播

Staleness

旧记录保留，但不再作为新规格的验收依据。

规格变更：支持 dtype 新增 bf16
正确性用例结果需重新验证

F07

控制语义

Control Verbs

是否支持、作用范围与剩余影响，以底层工具实际能力为准。

暂停作用于后续执行
取消结束任务推进
撤销针对某次编辑
回滚恢复已记录版本
已请求停止≠执行已停止

停止任务不等于自动回滚改动；设备任务未必能即时中断。

21/  Metrics

按层衡量效果，
先取基线再定目标值

用代表性任务获得基线，再按任务成本、用户差异和产品阶段设定目标。活跃度指标不能单独作为成功依据。

measure judgment, not activity

L0原语

  • 版本错配次数结论与当前对象版本不一致
  • 证据定位成功率正确找到证据 / 有效尝试
  • 未验证被当作可用验证阶梯被跳过的次数

L1模式

  • 上下文重述次数区分必要澄清与系统丢失
  • 局部任务完成时间提问到可用结果
  • 状态判断准确性能否说清任务进展

L2运行

  • 无效提示比例不成立 / 已核查提示
  • 有效实验产出率形成可用结论的运行占比
  • 资源冲突次数并行破坏测量条件

L3转场

  • 转场信息丢失项转场后用户补充的已有信息
  • 恢复理解时间返回到能说明状态与下一步
  • 现场恢复耗时返回画布后的选区与视图

Accept验收

  • 正确决策率预先定义可接受判断
  • 不可比较识别率能否识别口径不一致
  • 验收后返工比例区分新增需求与原任务遗漏
